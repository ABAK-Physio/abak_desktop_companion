Bienvenue dans ABAK Companion

Cet assistant installe ABAK Companion dans le dossier Applications.

Avant de commencer

Quittez toutes les copies d’ABAK Companion ouvertes. Si l’application est encore ouverte, l’installation sera interrompue : quittez-la, puis relancez cet assistant.

Première installation

Une fois l’installation terminée, ouvrez ABAK Companion depuis le dossier Applications.

Mise à jour

La copie située dans Applications sera remplacée. L’installateur ne supprime pas vos données ni vos préférences.

Vous utilisiez une copie dans Téléchargements ?

Après l’installation, ouvrez la copie située dans Applications et vérifiez votre version et vos données.

Si vous aviez créé un alias sur le Bureau, supprimez cet ancien alias et recréez-le depuis la copie située dans Applications.

Vous pourrez ensuite mettre les anciennes copies de l’application à la Corbeille, sans toucher à vos dossiers de données.
